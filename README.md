## Featured Projects

<details>
<summary><strong>⬡ &nbsp; Hybrid Neural-Symbolic Framework for Document Understanding & Mathematical Reasoning</strong></summary>

<br/>

A hybrid AI framework combining neural networks and symbolic reasoning to tackle document understanding and mathematical problem-solving — **accepted for oral presentation at ICSSAS 2026**.

<br/>

| Attribute | Details |
|:--|:--|
| **Stack** | Python · NLP · Neural-Symbolic AI · Machine Learning · Pandas · NumPy |
| **Scale** | Evaluated across multi-domain document corpora and mathematical reasoning benchmarks |
| **Performance** | Outperformed standalone neural and symbolic baselines on reasoning accuracy |
| **Impact** | Accepted for oral presentation at ICSSAS 2026 — International Conference on Smart Systems, Automation and Software |
| **Repository** | [![GitHub](https://img.shields.io/badge/View%20Repo-7C3AED?style=flat-square&logo=github&logoColor=white)](https://github.com/Aksh1tha) |

<br/>

**Technical breakdown:**

The system is built around a two-stage architecture. In the first stage, an NLP preprocessing pipeline handles raw document ingestion — performing tokenization, entity extraction, and structural parsing using Python and NumPy/Pandas to normalize inputs into a consistent representation. In the second stage, a hybrid inference engine routes sub-problems: pattern-heavy language tasks (context understanding, semantic similarity) are handled by the neural component, while precision-critical tasks (mathematical equations, logical deductions) are routed to the symbolic reasoning engine. The final output merges both branches into a coherent, explainable answer. This design consistently outperformed either approach used in isolation, particularly on documents that mixed natural language context with embedded mathematical content.

<details>
<summary><strong>⬡ &nbsp; Health Condition Analysis & Medication Recommendation System</strong></summary>

<br/>

An AI-powered clinical decision-support system that analyzes user-input symptoms via NLP to predict probable health conditions and recommends medications using sentiment analysis on drug reviews — achieving **~91% prediction accuracy** with a **~1.3s response time**.

<br/>

| Attribute | Details |
|:--|:--|
| **Stack** | Python · Scikit-learn · NLP (TF-IDF, NLTK, spaCy) · Flask · Pandas · NumPy · HTML/CSS/JS |
| **Scale** | Trained on real-world drug review datasets · Real-time web inference |
| **Performance** | ~91% prediction accuracy · ~1.3s average response time |
| **Impact** | Production-ready healthcare decision-support prototype with full end-to-end ML pipeline |
| **Repository** | [![GitHub](https://img.shields.io/badge/View%20Repo-7C3AED?style=flat-square&logo=github&logoColor=white)](https://github.com/Aksh1tha) |

<br/>

**Technical breakdown:**

The ML pipeline starts with raw symptom text entered by the user. It goes through tokenization and stopword removal using NLTK/spaCy, then TF-IDF vectorization converts the cleaned text into numerical feature vectors. These vectors are fed into a **Passive Aggressive Classifier** — a linear model well-suited for high-dimensional text data and fast online learning — trained on a labeled multi-class disease dataset to output a predicted condition. A second model handles medication recommendations: it processes a drug review dataset through sentiment analysis, scoring each drug's community-reported effectiveness. The top-ranked medications for the predicted condition are surfaced as recommendations. Both models are served through a **Flask** backend with a lightweight HTML/CSS/JS frontend, delivering real-time predictions in under 1.3 seconds per request.

</details>
